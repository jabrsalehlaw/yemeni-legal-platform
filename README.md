# المنصة القانونية اليمنية — النسخة المستقلة v0.3

هذه النسخة لا تعتمد على Blogger. تم الاحتفاظ بأفكار ووظائف القالب السابق مع فصلها عن نظام قوالب Blogger.

## ما تم الحفاظ عليه
- هوية المنصة العربية RTL والثيم الداكن.
- البحث في المحتوى.
- القراءة الصوتية العربية.
- تنسيق المواد القانونية.
- استخراج PDF إلى محتوى قابل للعرض.
- محرك العقود التفاعلي العام.
- الخانات المعرّفة داخل العقد بصيغة `[[اسم الخانة|key=...|type=...]]`.
- تكرار الخانة نفسها وربطها بقيمة واحدة.

## قاعدة البيانات الجديدة
قاعدة البيانات المستهدفة هي Cloudflare D1. المخطط موجود في:
`database/schema.sql`

والبيانات الابتدائية البسيطة في:
`database/seed.sql`

المحتوى القديم غير مفروض على المشروع. سيتم إدخال قاعدة بيانات جديدة وتنظيمها من البداية.

## التشغيل المحلي
```bash
npm install
npm run check
npm run dev
```

## النشر
بعد إنشاء D1 قاعدة بيانات وربط `database_id` داخل `wrangler.jsonc`:
```bash
npx wrangler d1 execute yemeni-legal-db --file=database/schema.sql
npx wrangler d1 execute yemeni-legal-db --file=database/seed.sql
npm run deploy
```
